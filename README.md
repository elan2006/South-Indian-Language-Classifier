# South Indian Language Classifier

A model to classify whether an image of a writing belongs to any of the four major South Indian Languages, namely: Tamil, Malayalam, Kannada, Telugu.

The model is a finetuned version of the Resnet18 model trained on generated images of text scraped from Wikipedia.

`scrape.ipynb` - contains the code to scrape the data and generate the dataset
`train.ipynb` - contains the code to finetune the Resnet18 model
